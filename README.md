# BTS 투자철학

Bitcoin · Time · Self를 함께 살펴보는 개인 대시보드입니다.

[BTS 투자철학 열기](https://bts-investment-philosophy-app.streamlit.app/)

- **B:** 비트코인·테더의 원화와 달러 가격, 원/달러 환율, 한국·미국 기준금리
- **T:** 멤풀의 예상 대기 블록과 확정된 블록, 권장 수수료, 반감기 진행 현황
- **S:** 노션에서 관리하는 개인 노력 기록 카드

## 자료 기준과 갱신

원화 가격은 업비트, 달러 가격은 Coinbase Exchange의 실제 거래 가격입니다. 최근 체결시각과 조회시각을 함께 표시합니다. 환율은 ECB가 영업일마다 공표하는 유로 기준 USD·KRW 환율로 계산한 1 USD당 KRW 참조환율입니다.

한국 기준금리는 한국은행의 최근 변경 자료를 사용하며, 연결이 지연되면 한국은행이 국제결제은행(BIS)에 제공한 일별 자료로 대체합니다. 대체 자료의 기준일과 갱신 지연을 화면에 표시합니다. 미국은 뉴욕 연방준비은행이 공표한 연방기금금리 목표범위의 상·하한입니다. 기준일과 조회시각을 각 카드에 표시합니다.

멤풀 자료는 mempool.space에서 읽습니다. 반감기는 현재 블록 높이로 계산하며, 예상 날짜는 조회 시점부터 블록당 평균 10분을 가정한 추정치입니다. 수수료의 목표시간과 반감기 예상일은 보장된 일정이 아닙니다.

화면이 열려 있는 동안 시세·블록은 1분마다 갱신하고, 환율·기준금리는 1시간마다 확인합니다. **자료 새로고침**을 누르면 즉시 다시 조회합니다. 조회 실패를 임의의 숫자로 대체하지 않으며, 다른 자료와 노션 기록은 계속 표시합니다.

## S 기록 관리

노션의 `BTS 투자철학 · Self 기록`에서 활동을 관리합니다. `보드에 표시`를 체크한 활동만 `표시 순서` 오름차순으로 나타납니다. 같은 순서는 최근 수정순이며, 순서가 비어 있으면 뒤에 표시됩니다. 내용을 수정한 뒤 앱의 **기록 새로고침**을 누르세요.

## 로컬 실행

```sh
pip install -r requirements.txt
streamlit run streamlit_app.py
```

노션 연결은 `NOTION_TOKEN`과 `NOTION_DATA_SOURCE_ID` 설정을 사용합니다. 배포 환경에서는 Streamlit Secrets에 저장하며, 인증키를 코드나 저장소에 넣지 않습니다. B·T 영역은 공개 자료를 사용하므로 별도 인증키가 필요하지 않습니다.
