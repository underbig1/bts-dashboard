# BTS investment philosophy

save Bitcoin · trust Time · grow Self

[BTS investment philosophy 열기](https://bts-investment-philosophy-app.streamlit.app/)

페이지 상단에 배너 이미지를 표시하고, 같은 페이지에서 바로 대시보드를 보여줍니다.

- **save Bitcoin:** 비트코인 원화·달러 가격
- **trust Time:** 작은 입체 블록, 대기 거래·수수료·반감기 참고 정보
- **grow Self:** 노션에서 관리하는 개인 노력 기록

각 영역의 B·T·S는 다른 글자보다 두 배 크게 표시하며, 오렌지·청회색·초록색으로 강조합니다. 제목 옆에는 각각 비트코인 로고·시계·새싹 아이콘을 표시합니다.

## 공유와 홈 화면 설치

[공유·설치 링크 열기](https://underbig1.github.io/bts-investment-philosophy/)

갤럭시에서는 위 링크를 **Chrome**으로 열고 화면의 **설치** 또는 **홈 화면에 추가**를 누릅니다. 설치 안내가 나오면 Chrome의 **⋮ → 홈 화면에 추가 또는 설치**를 선택하고 BTS 아이콘을 확인합니다. 다른 분께 공유할 때도 위 GitHub Pages 링크를 사용합니다.

설치 화면은 기존 Streamlit 대시보드를 iframe으로 표시합니다. 저장소와 Streamlit 백엔드는 기존 것을 그대로 사용하며, 대시보드를 보려면 인터넷 연결이 필요합니다.

관리자 참고: GitHub Pages 게시 원본은 `main` 브랜치의 `/(root)`입니다. 설치 아이콘은 제공받은 1254×1254 PNG 원본을 사용합니다. Android Chrome의 아이콘 크기 조건에 맞지만, 데스크톱 Chromium은 1024px 제한으로 설치 아이콘 검사가 실패할 수 있습니다. 실제 갤럭시에서 설치와 실행을 확인하는 절차는 아직 완료하지 않았습니다.

## 자료 기준과 갱신

원화 가격은 업비트, 달러 가격은 Coinbase Exchange의 실제 거래 가격입니다. 출처와 조회시각은 앱 화면에서 생략하며, 시세가 15분 이상 오래되면 숫자 대신 —를 표시합니다.

멤풀 자료는 mempool.space에서 읽습니다. 파란 블록은 실제 확정 블록, 금색 블록은 현재 대기 거래의 예상 묶음입니다. 대기 블록의 부유 효과는 시각 효과이며 채굴을 뜻하지 않습니다. 새 확정 블록은 실제 블록 높이가 증가한 경우에만 진입 효과를 적용합니다.

확정 블록 2개와 예상 대기 블록 2개를 표시하며, 각 블록은 이전보다 15% 크게 보여줍니다. 블록을 누르면 mempool.space의 해당 확정 블록 또는 예상 대기 블록 상세 정보가 열립니다. 첫 번째·두 번째 예상 대기 블록은 각각 `/mempool-block/0`·`/mempool-block/1`에 연결됩니다.

T 영역의 멤풀 블록 바로 아래에는 “10년 이상 들고 가지 않을 자산은 10분도 들고 있지 않겠다.”라는 슬로건을 한글 필기체로 표시합니다.

반감기는 현재 블록 높이로 계산합니다. 예상 날짜는 블록당 평균 10분을 가정하며, 수수료의 목표시간과 반감기 예상일은 보장된 일정이 아닙니다.

대시보드가 열려 있는 동안 시세·블록은 1분마다 갱신합니다. 상단 **↻**를 누르면 공개 자료와 노션 기록을 다시 읽습니다.

## S 기록 관리

노션의 `BTS 투자철학 · Self 기록`에서 활동을 관리합니다. `보드에 표시`를 체크한 활동만 `표시 순서` 오름차순으로 나타납니다. 같은 순서는 최근 수정순이며, 순서가 비어 있으면 뒤에 표시됩니다.

기록 제목은 기존보다 약 30% 작게 표시합니다. 카드에는 분야에 따라 독서는 연한 금색, 운동은 연한 초록색, 프로젝트는 연한 파란색 배경을 적용합니다.

‘민음사 세계고전 501권 읽기’ 카드의 어느 곳을 눌러도 [공개 노션 독서 기록](https://tropical-hub-028.notion.site/501-3cfaa88e004181e19859f86af00cad1f)이 새 탭으로 열립니다.

## 로컬 실행

```sh
pip install -r requirements.txt
streamlit run streamlit_app.py
```

노션 연결은 `NOTION_TOKEN`과 `NOTION_DATA_SOURCE_ID` 설정을 사용합니다. 배포 환경에서는 Streamlit Secrets에 저장하며, 인증키를 코드나 저장소에 넣지 않습니다. B·T 영역에는 별도 인증키가 필요하지 않습니다.

상단 배너는 저장소의 `Codex 이미지 2026년 9월 14일 오후 04_23_51.png` 원본을 사용합니다. 이미지는 `streamlit_app.py`와 같은 폴더에 둡니다.
